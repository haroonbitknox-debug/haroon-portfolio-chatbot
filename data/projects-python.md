# Python and AI Projects

## Zara Blog Chatbot (Flask and Gemini)
Zara is an AI blogging assistant. It writes blog posts from a topic, suggests titles and outlines, and polishes existing paragraphs.
Tech stack: Python, Flask, Gemini API, deployed on Vercel.
Live demo: https://haroons-chatbot.vercel.app/
Haroon built it while teaching at Brains College, giving the chatbot a blog-writing personality. His students built their own chatbots using the same approach, including a gamer chatbot (https://gamer-chatbot.vercel.app/) and Edify (https://edify-by-sohani.vercel.app/). These two are student projects.

## RAG Document Scanner Chatbot
A chatbot where users upload documents and ask questions about them. It retrieves the relevant parts of the document and answers from them, so answers are grounded in the text.
Tech stack: Python, LangChain, Streamlit, embeddings, and a vector database.
Live demo: https://haroonbitknox-debug-rag-based-document-scanner-chatb-app-ntl8fg.streamlit.app/
He built it during the HCCDA-AI program and learned chunking, embeddings, vector search, and RAG pipelines.

## Portfolio AI Assistant (FastAPI and LangChain)
The assistant on this portfolio is a RAG chatbot. It answers questions about Haroon from his own resume and project notes.
Tech stack: FastAPI, LangChain, FAISS, Gemini API, with streaming responses, source attribution, and rate limiting. The frontend is a React chat widget.
