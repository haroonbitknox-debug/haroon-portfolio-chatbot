# Company and Internship Projects

## Anchorage Islamabad Website and Admin Mobile App Backend (BITS)
Haroon optimized the website of Anchorage Islamabad, a housing society, and built APIs for its admin mobile application. This was his first job as a web developer at Business Innovation and Tech Solutions.
Results:
- Reduced website loading time from 5 seconds to 2 seconds.
- Upgraded the code from Laravel 8 to Laravel 10.
- Delivered 20+ RESTful APIs for the mobile app, working with the mobile app developer.
- Built 3 extra modules: complaint management, picture uploading and saving, and bill payment for complaints.

Hardest challenge: the complaints API. When a resident files a complaint, only the head of department (HOD) of that department should be notified. For example, the HOD of the electrical department only receives electrical complaints, and no other department receives them. Only the super admin can see all complaints. Haroon designed the API logic and notifications to enforce this.

## HR Management System (Bitknox Global internship)
Haroon designed and built the HR module for the company during a 3-month internship.
Features:
- Online employee attendance tracking.
- Leave management.
- Create, read, update, and delete (CRUD) operations on employees, restricted to HR users only.

Tech stack: React for the frontend, Laravel for the backend APIs and routes, and MySQL.
What he learned: migrations, MySQL, seeders, controller optimization, and professional work ethics.
