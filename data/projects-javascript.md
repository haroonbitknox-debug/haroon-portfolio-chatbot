# JavaScript, React, and MERN Projects

## Automated Content Submission Evaluation System (Final Year Project)
Haroon's final year project, built with the MERN stack. CS students can sign up and sign in, upload videos, receive feedback, and see their scores and how their work ranks against others.
Tech stack: MongoDB, Express, React, Node.js.

## Portfolio Website

Live site: https://haroon-portfolio-iota.vercel.app/
GitHub: https://github.com/haroonbitknox-debug

## React Practice Projects (Bano Qabil course)
During the Bano Qabil course, Haroon built live React projects, using every React hook and conditional rendering, and won first position. The projects include a stopwatch, a digital clock, a dark/light theme switcher, a weather app, a calculator, and a todo app.
